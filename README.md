# User List App (React Native)

## 🚀 Features

* Fetch users from API
* Display in FlatList
* Search by name & email
* User detail screen
* Responsive layout

## 🛠 Tech Stack

* React Native (Expo)
* Expo Router
* JavaScript / TypeScript

## ▶️ Run Locally

```bash
npm install
npm start
```
